## 0.1.x

* Menu-Data-Network access
  New interface for get data directly from device and put files on device.
  Get data: starts web server and serve http requests. Allow to download all current data as single xTrack file
  Put data: upload any selected file to specified directory on device
* Changed storage format to v3. Incompatible.
* Changed filter dialog: removed images\notes nodes, removed metainfo slection in waypoints and notes.
* Modal progress on: clear data, import, export
* Changed settings: map view and path builder selectors with personal settings
* Changed default offline map view. Now it uses vector maps from "protomaps.com" and allow to use custom scales
