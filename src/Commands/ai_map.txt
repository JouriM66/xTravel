русский текст для того чтобы редакторы не путали кодировку

src\Commands\ - самостоятельные функции, вызываемые из главного меню. В код сюда лазят редко.
Сам реестр команд и их контракт - в src\AppCommand.kt, пункты меню - в src\MainMenu.kt.

DataSheet.kt - дерево выбора данных на шторке, общее для трёх операций.
  DataOperation (отправить, импортировать, очистить), DataContent, DataCounts,
  DataSelect: openShare, openClear, openImport.
  Ветки: точки, маршруты, записки, треки; галка переносится на всех потомков.
  Строки-фильтры "изображения" и "заметки" принадлежат ВЕТКЕ ТОЧЕК: элементы записок
    им не подчиняются ни в одной из трёх операций, у записок только свои галки.
  Уход со шторки - отмена; у импорта при этом удаляется временный каталог.
  Отправка: кнопка тулбара - общее меню "поделиться" (Storage\GeoDataShare.kt) с отмеченным набором.
  Записки в дереве - MetaInfo, их строки с ключами n#индекс.
  Точки входа: AppCommands.shareData, AppCommands.clearData и DataImport из Storage\DataIO.kt,
    который после распаковки зовёт openImport.

FilesCheck.kt
  FilesCheck: пункт "Уборка данных". Обход AppDirs.base в потоке "io"; лишний файл - тот,
    на который не указывают загруженные данные. Пустые каталоги удаляются при обходе,
    лишние файлы - только после согласия пользователя.

AboutScreen.kt - окно "О программе" и сведения о лицензиях для него.
  AboutScreen: описание приложения, строка версии (appVersion из utils) и список ПО,
    HTML со ссылками.
  LicenseInfo, ILicenseInfo, LicenseManager: register и licenseInfo.
    LicenseManager лежит здесь, потому что существует только ради этого окна.
    Поставщиков (YandexMapEngine, YandexSearchEngine) записывает XTravelApp при запуске;
    поставщик без своего ключа возвращает пустой массив, поэтому список зависит от настроек.
