русский текст для того чтобы редакторы не путали кодировку

src\Commands\ - самостоятельные функции, вызываемые из главного меню. В код сюда лазят редко.
Сам реестр команд и их контракт - в src\AppCommand.kt, пункты меню - в src\MainMenu.kt.

DataSheet.kt - дерево выбора данных на шторке, общее для трёх операций.
  DataOperation (отправить, импортировать, очистить), DataContent, DataCounts,
  DataSelect: openShare, openClear, openImport.
  Ветки: точки, маршруты, треки и одна строка записок; галка переносится на всех потомков.
  Точка и записки выбираются целиком, со всем содержимым; справа у них "тексты/картинки".
  Размеры - DataContent.fileSize: у своих данных с диска, у импорта от ImportSource; неизвестный размер не выводится.
  Уход со шторки - отмена.
  Очистка идёт под AppDialog.busy "Удаление данных"; окно закрывается, когда очередь "io" (удаление файлов треков) пройдена.
  Импорт: кнопка "Загрузить" зовёт DataImport.apply из Storage\DataImport.kt.
  Отправка: кнопка тулбара - общее меню "поделиться" (Storage\GeoDataShare.kt) с отмеченным набором.
  Записки в дереве - MetaInfo, их строки с ключами n#индекс.
  Точки входа: AppCommands.shareData, AppCommands.clearData и DataImport из Storage\DataImport.kt,
    который после чтения data.xml зовёт openImport(source).

NetAccess.kt - пункт "Сетевой доступ" меню "Данные".
  NetAccess.open: диалог AppDialog с адресами http://<IPv4>:<порт>/ только Wi-Fi и раздачи точки доступа
    (сотовые, VPN, USB отброшены; Wi-Fi по ConnectivityManager и по имени интерфейса), каталогом приёма
    с кнопкой "Указать" и кнопками "Закрыть" и "Поделиться" (адреса текстом). Сервер живёт, пока диалог
    в композиции: любой AppDialog.show поверх него сервер останавливает. Пока открыт, экран не гаснет.
    Порт 8080, занят - следующий из 20.
  Сервер: POST /upload - приём, GET|HEAD /download... - архив, любой другой путь GET - страница;
    цель запроса в полной форме (через прокси) сводится к пути.
  Страница браузера: скачать весь набор (DataIO.writeExport, без globals, имя XTravelShare.fileName)
    и загрузить файл: сохраняется под своим именем в каталог приёма, без импорта.
    Каталог приёма - Settings.uploadFolder (дерево SAF с постоянным разрешением), пусто - Download через
    utils saveToDownloads (Android 10+, ниже без выбора каталога приём невозможен).

FilesCheck.kt
  FilesCheck: пункт "Уборка данных". Обход AppDirs.base в потоке "io"; лишний файл - тот,
    на который не указывают загруженные данные. Пустые каталоги удаляются при обходе,
    лишние файлы - только после согласия пользователя.

AboutScreen.kt - окно "О программе" и сведения о лицензиях для него.
  AboutScreen: описание приложения, строка версии (appVersion из utils) и список ПО,
    HTML со ссылками.
  LicenseInfo, ILicenseInfo, LicenseManager: register и licenseInfo.
    LicenseManager лежит здесь, потому что существует только ради этого окна.
    Поставщиков (YandexMapEngine, YandexSearchEngine, VectorMapLicense) записывает XTravelApp при запуске;
    поставщик без своего ключа возвращает пустой массив, поэтому список зависит от настроек.
